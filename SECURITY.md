# Security Policy

## Reporting a Vulnerability

If you discover a security issue, please report it by opening an issue in the repository and prefacing the title with `SECURITY:`.

Include:

- a clear summary of the vulnerability
- steps to reproduce
- affected versions or branches
- any proof-of-concept details

If you need to share sensitive information, please use a private communication channel if available.

## Supported Versions

This repository is based on Laravel 12 and PHP 8.2.

Security support is provided for the current release branch and immediate maintenance updates.

## Disclosure Policy

We prefer coordinated disclosure. Please avoid publishing details until the issue has been addressed.

## Security Contact

If an issue needs urgent attention, mention the project maintainer in the repository or use the repository issue tracker.
